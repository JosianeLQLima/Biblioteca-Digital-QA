# 📚 Biblioteca Digital QA

> **Projeto de Portfólio em Qualidade de Software (QA)**

Este projeto simula a atuação de um **Analista de Qualidade de Software (QA)** em uma plataforma de **Biblioteca Digital**. O objetivo é demonstrar, de forma prática, as principais atividades desempenhadas por um profissional de QA durante o ciclo de desenvolvimento de software, desde a análise dos requisitos até a documentação dos testes e registro de defeitos.

---

# 🎯 Objetivo

Desenvolver um projeto completo de QA para uma Biblioteca Digital fictícia, aplicando boas práticas de testes de software para garantir a qualidade, confiabilidade e usabilidade da aplicação.

Este projeto foi criado para compor meu portfólio profissional e demonstrar minhas competências em:

* Planejamento de Testes
* Testes Manuais
* Testes Exploratórios
* Criação de Casos de Teste
* Checklists
* Relatórios de Bugs
* Testes de API
* Validação de Banco de Dados com SQL
* Organização de documentação técnica

---

# 📖 Sobre o Sistema

A Biblioteca Digital é uma plataforma fictícia que permite aos usuários pesquisar livros, realizar empréstimos, renovar empréstimos, devolver livros e gerenciar seu perfil.

O sistema possui funcionalidades voltadas tanto para usuários quanto para administradores da biblioteca.

# 🧪 Escopo dos Testes

Este projeto contempla atividades de QA em diferentes níveis.

## Testes Funcionais

* Cadastro
* Login
* Recuperação de senha
* Pesquisa de livros
* Empréstimos
* Renovação
* Devolução
* Favoritos
* Perfil

## Testes Exploratórios

Execução de testes livres para identificação de comportamentos inesperados.

## Testes de API

Validação dos principais endpoints utilizando Postman.

## Validação de Banco de Dados

Consultas SQL para verificar integridade e consistência das informações.
