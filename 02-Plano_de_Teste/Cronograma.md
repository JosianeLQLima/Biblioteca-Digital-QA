# 1. Objetivo

Este documento apresenta o cronograma das atividades previstas para o planejamento, elaboração, execução e documentação dos testes da aplicação **Biblioteca Digital**.

---

# 6. Critérios para Avanço das Etapas

Cada fase somente poderá ser iniciada quando a etapa anterior estiver concluída.

Exemplos:

* Os casos de teste somente serão elaborados após a conclusão dos requisitos.
* A execução dos testes ocorrerá apenas após a preparação do ambiente.
* Os retestes dependerão da correção dos bugs identificados.
* A matriz de rastreabilidade será criada após a conclusão da execução dos testes.

* Documentação de Requisitos.
* Plano de Testes.
* Escopo dos Testes.
* Casos de Teste.
* Checklist de Testes.
* Relatórios de Bugs.
* Evidências da Execução.
* Coleção Postman para testes de API.
* Scripts SQL para validação dos dados.
* Matriz de Rastreabilidade.
* Apresentação Final do Projeto.

---

# 9. Conclusão

Este cronograma organiza todas as atividades do projeto Biblioteca Digital QA conforme o ciclo de vida de testes (STLC), garantindo rastreabilidade, organização e uma sequência lógica para planejamento, execução e documentação das atividades de qualidade de software.
